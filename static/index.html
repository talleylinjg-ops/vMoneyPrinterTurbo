SaaS 调用参数

      
你的站点只需 POST 创建任务，再轮询状态。用户不用填写几十个参数，前端给默认值即可。

      
POST /api/v1/videos
Content-Type: application/json

{
  "video_subject": "人工智能如何改变日常生活",
  "video_script": "",
  "video_terms": "artificial intelligence, daily life",
  "language": "zh-CN",
  "video_source": "pexels",
  "aspect": "9:16",
  "clip_duration": 3,
  "voice_name": "zh-CN-XiaoxiaoNeural",
  "subtitle_enabled": true
}

GET /api/v1/videos/{task_id}
GET /api/v1/videos/{task_id}/preview
GET /api/v1/videos/{task_id}/download
GET /api/v1/options
GET /docs/saas
GET /openapi.json

常见问题

      
MoneyPrinterTurbo 收费吗？

      
完全免费。素材来自 Pexels / Pixabay，配音使用 Edge TTS，不调用大模型。

      
如何生成短视频？

      
在首页填写视频主题或文案，选择画幅后点击生成。系统会自动匹配素材、配音、字幕并合成成片。

      
SaaS 如何调用？

      
POST /api/v1/videos 提交任务，轮询 GET /api/v1/videos/{task_id} 直到 state=complete，再用 /preview 或 /download 取回成片。规格见 /openapi.json，说明见 /docs。

      
有哪些限制？

      
文案最多 1500 字，成片约 180 秒。这是全新生成流水线，不支持时间轴精修已有视频。
