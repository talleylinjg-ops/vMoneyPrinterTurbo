MoneyPrinterTurbo 静态版输入主题或文案，在浏览器内生成本地旁白、关键词和带字幕的 WebM 成片。无回源后端，不调用大模型。全新生成流水线，不支持时间轴精修已有视频。

    


    

      
如何使用

      
打开首页填写主题，点击生成。成片在浏览器内完成。说明见 /docs，模型导览见 /llms.txt。

      
1. 填写视频主题或自定义文案
2. 选择画幅 9:16 或 16:9
3. 点击「生成视频」
4. 预览或下载 WebM
5. 同一浏览器刷新后，任务管理可再取回

    


    

      
常见问题

      
MoneyPrinterTurbo 收费吗？

      
完全免费。Cloudflare 纯静态托管，文案和成片都在浏览器完成。

      
如何生成短视频？

      
在首页填写视频主题或文案，选择画幅后点击生成。浏览器会生成本地文案并渲染带字幕的成片。

      
需要后端 API 吗？

      
不需要。本站无回源。打开首页即可生成，任务保存在本机 IndexedDB。说明见 /docs。

      
有哪些限制？

      
文案最多 1500 字，成片约 180 秒。成片是浏览器渲染的字幕画面。全新生成流水线，没有时间轴精修。

      
成片会丢失吗？

      
成片保存在本机 IndexedDB。同一浏览器刷新后仍可预览和下载。

      
需要配置大模型吗？

      
不需要。静态版关闭 LLM，文案和关键词在浏览器本地生成。
