如何一键生成短视频

      

        

          
1. 填写主题或文案

          
输入「人工智能如何改变日常生活」这类主题，或粘贴最多 1500 字旁白。可不填大模型 Key。

        

        

          
2. 选画幅与配音

          
竖屏 9:16、横屏 16:9 或方形 1:1。音色默认 zh-CN-XiaoxiaoNeural，可试听 Edge TTS。

        

        

          
3. 生成并下载

          
点击生成后轮询进度。完成态为 complete，用预览播放或下载 MP4。刷新后 task_id 仍有效。

常见问题

      
MoneyPrinterTurbo 收费吗？

      
完全免费。素材来自 Pexels / Pixabay，配音使用 Edge TTS，不调用大模型。

      
如何生成短视频？

      
在首页填写视频主题或文案，选择画幅后点击生成。系统会自动匹配素材、配音、字幕并合成成片。

      
SaaS 如何调用？

      
POST /api/v1/videos 提交任务，按返回的 poll_after_ms 轮询 GET /api/v1/videos/{task_id} 直到 state=complete，再用 preview / download 绝对地址取片。支持 Range，二次下载走边缘 R2。规格见 /openapi.json，说明见 /docs。

      
有哪些限制？

      
文案最多 1500 字，成片约 180 秒。这是全新生成流水线，不支持时间轴精修已有视频。

      
成片会丢失吗？

      
成片落盘保存。刷新页面后仍可用 task_id 预览和下载。

      
需要配置大模型吗？

      
不需要。托管版关闭 LLM，文案和关键词在本地生成，素材来自 Pexels / Pixabay，配音使用 Edge TTS。

      
适合做什么短视频？

      
适合知识科普、产品介绍、旅行见闻、新闻摘要、口播解说类竖屏或横屏短视频。画幅支持 9:16、16:9、1:1。

      
和官方 Streamlit 版有什么区别？

      
本托管站关闭大模型、完全免费，提供开放 SaaS API 和 Cloudflare 边缘静态页。官方仓库仍保留在 MoneyPrinterTurbo/。
