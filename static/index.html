SaaS 调用参数

      
你的站点只需 POST 创建任务，再轮询状态。用户不用填写几十个参数，前端给默认值即可。

      
POST /api/v1/videos
Content-Type: application/json

{
  "video_subject": "人工智能如何改变日常生活",
  "video_script": "",
  "video_terms": "artificial intelligence, daily life",
  "language": "zh-CN",
  "video_source": "pexels",
  "aspect": "9:16",
  "clip_duration": 3,
  "voice_name": "zh-CN-XiaoxiaoNeural",
  "subtitle_enabled": true
}

GET /api/v1/videos/{task_id}
GET /api/v1/videos/{task_id}/preview
GET /api/v1/videos/{task_id}/download
GET /api/v1/options
GET /docs/saas
