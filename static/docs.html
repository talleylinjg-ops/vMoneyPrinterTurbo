首页 / SaaS 文档

认证

引擎直连无需 Key。门户调用带 x-api-key，浏览器预览可用 ?api_key=。

提交任务

POST __ORIGIN__/api/v1/videos

{
  "video_subject": "春天适合出发",
  "video_script": "",
  "aspect": "9:16",
  "video_source": "pexels"
}

返回 {"task_id":"...","state":"queued"}。主题和文案至少填一项。

轮询

GET __ORIGIN__/api/v1/videos/{task_id}

state=complete 可预览下载；failed 看 error。

预览与下载

GET __ORIGIN__/api/v1/videos/{task_id}/preview
GET __ORIGIN__/api/v1/videos/{task_id}/download

成片落盘，刷新后仍可用同一 task_id。没有时间轴精修接口。

curl

curl -X POST __ORIGIN__/api/v1/videos \
  -H "Content-Type: application/json" \
  -d '{"video_subject":"春天适合出发","aspect":"9:16"}'

curl __ORIGIN__/api/v1/videos/TASK_ID
curl -L __ORIGIN__/api/v1/videos/TASK_ID/download -o video.mp4

限制

  • 文案最多 1500 字，成片约 180 秒。
  • 完全免费：Pexels / Pixabay + Edge TTS，不调用大模型。
  • 全新生成流水线，不支持时间轴精修已有视频。

常见问题

引擎直连需要 API Key 吗？

不需要。引擎 /api/v1/videos 开放调用。门户 /api/proxy/v1/videos 需要 x-api-key。

完成态是什么？

成功为 complete，失败为 failed。不要用 succeeded 判断。

能精修已有视频吗？

不能。这是全新生成流水线，没有时间轴精修接口。改内容需重新 POST。
