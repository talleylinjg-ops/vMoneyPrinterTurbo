首页 / 使用说明

站点形态

本站托管在 Cloudflare Workers + R2 + Assets，无回源后端。文案、关键词、字幕成片和试听都在浏览器完成。

生成步骤

1. 打开 __ORIGIN__/
2. 填写视频主题或自定义文案
3. 选择画幅 9:16 或 16:9
4. 点击「生成视频」
5. 预览或下载 WebM

任务保存在本机 IndexedDB。同一浏览器刷新后，任务管理仍可取回。

能力边界

  • 文案最多 1500 字，成片约 180 秒。
  • 成片是浏览器 Canvas + MediaRecorder 渲染的字幕画面，格式 WebM。
  • 试听使用浏览器 SpeechSynthesis，成片不含 TTS 音轨。
  • 完全免费，不调用大模型，无需 API Key。
  • 全新生成流水线，不支持时间轴精修已有视频。

常见问题

需要 API Key 吗？

不需要。本站是 Cloudflare 纯静态页，无回源 API。

成片存在哪里？

浏览器 IndexedDB。同一浏览器刷新后仍可预览下载。

能精修已有视频吗？

不能。这是全新生成流水线，没有时间轴精修接口。

需要配置大模型吗？

不需要。静态版关闭 LLM，文案和关键词在浏览器本地生成。
