首页 / SaaS 文档

认证

引擎直连无需 Key。门户调用带 x-api-key，浏览器预览可用 ?api_key=。

提交任务

POST https://moneyprinterturbo.chacha.asia/api/v1/videos

{
  "video_subject": "春天适合出发",
  "video_script": "",
  "aspect": "9:16",
  "video_source": "pexels"
}

返回 task_id、state、status_url、preview、download、poll_after_ms。主题和文案至少填一项。

轮询

GET https://moneyprinterturbo.chacha.asia/api/v1/videos/{task_id}

按返回的 poll_after_ms（默认 1500）间隔请求。state=complete 后直接用绝对地址 preview / download；failed 看 error。

预览与下载

GET https://moneyprinterturbo.chacha.asia/api/v1/videos/{task_id}/preview
GET https://moneyprinterturbo.chacha.asia/api/v1/videos/{task_id}/download

支持 Range / HEAD 断点续传。首次回源引擎，二次下载走 Cloudflare R2。成片落盘，刷新后仍可用同一 task_id。

curl

curl -X POST https://moneyprinterturbo.chacha.asia/api/v1/videos \
  -H "Content-Type: application/json" \
  -d '{"video_subject":"春天适合出发","aspect":"9:16"}'

# 轮询直到 state=complete（建议间隔 poll_after_ms）
curl https://moneyprinterturbo.chacha.asia/api/v1/videos/TASK_ID

# 用返回的 download 绝对地址，支持断点续传
curl -L -C - https://moneyprinterturbo.chacha.asia/api/v1/videos/TASK_ID/download -o video.mp4

限制

  • 文案最多 1500 字，成片约 180 秒。
  • 完全免费：Pexels / Pixabay + Edge TTS，不调用大模型。
  • 全新生成流水线，不支持时间轴精修已有视频。

常见问题

引擎直连需要 API Key 吗？

不需要。引擎 /api/v1/videos 开放调用。门户 /api/proxy/v1/videos 需要 x-api-key。

完成态是什么？

成功为 complete，失败为 failed。不要用 succeeded 判断。

能精修已有视频吗？

不能。这是全新生成流水线，没有时间轴精修接口。改内容需重新 POST。

需要配置大模型吗？

不需要。托管版关闭 LLM，文案和关键词在本地生成。
