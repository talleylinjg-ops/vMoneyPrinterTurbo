Free short-video generator

MoneyPrinterTurbo hosted edition turns a topic or script into a voiced, subtitled MP4. It matches Pexels / Pixabay clips, synthesizes Edge TTS, burns captions, and exports 9:16, 16:9 or 1:1. Price is zero. The engine does not call a large language model and does not require an API key.

How to generate

  1. Open the home page and enter a topic or paste a script.
  2. Pick aspect ratio and an Edge TTS voice.
  3. Click generate. Poll until state=complete, then preview or download.

Chinese walkthrough: /guide. SaaS spec: /docs, /openapi.json.

SaaS API

POST https://moneyprinterturbo.chacha.asia/api/v1/videos
Content-Type: application/json

{"video_subject":"How AI changes daily life","aspect":"9:16"}

GET https://moneyprinterturbo.chacha.asia/api/v1/videos/{task_id}
GET https://moneyprinterturbo.chacha.asia/api/v1/videos/{task_id}/download

The create response includes status_url, preview, download and poll_after_ms. Repeat downloads are served from Cloudflare R2 with Range support.

FAQ

Is it free?

Yes. Pexels / Pixabay footage plus Edge TTS. No LLM.

Do I need an API key?

Not on the engine. The optional portal uses x-api-key.

Can I edit an existing video?

No. Post a new job if you need different content.

What are the limits?

Script 1500 characters. Video about 180 seconds. Stock footage is licensed by Pexels / Pixabay, not AI-native video.

Does refresh lose the file?

No. The MP4 stays on disk. Reuse the same task_id.
